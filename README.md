# Gold-Trail
风雪压着北境驿道，碎金却在路上发亮。你可以做走私者，把金子运到边境黑市换取声望；也可以做官兵，巡查截运，并把金子送往墨尔根。绕路、采矿、设卡、出牌——每一程都可能让局势翻盘。走私者**从金矿取得碎金，送到边境黑市兑换；**官兵**可以稽查走私者，并将碎金运到墨尔根兑换。兑换会为阵营增加声望。 - 每名角色每回合掷行动骰，获得 **2–4 点行动点**，用来移动、采矿、补给或购买装备。卡牌和路上遭遇会带来额外机会，也可能让计划改道。 - **竞速局**：先达到 50 声望的阵营获胜。**火并局**：进行 30 轮后比较声望；同分平局。 - 一局有四名角色、双方各两人。人机版由你控制一方的两名角色；同屏模式由玩家轮流操作全部角色。
