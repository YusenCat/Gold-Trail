# 二十二驿 · 黄金邮道

> **开发版本：1.0.0｜本地可玩版**  
> **目前支持：** 本地人机对战（可选走私者或官兵）、同屏轮流游玩、竞速局与 30 轮火并局；完整地图、道路遭遇、行动骰、卡牌、事件和可命名存档。无需联网，也无需安装项目依赖。

风雪压着北境驿道，碎金却在路上发亮。你可以做走私者，把金子运到边境黑市换取声望；也可以做官兵，巡查截运，并把金子送往墨尔根。绕路、采矿、设卡、出牌——每一程都可能让局势翻盘。

## 开始一局

1. 安装 **Node.js 24 或更高版本**。
2. Windows 双击 `启动游戏.cmd`，在打开的页面选择“本地人机”或“同屏对局”。启动窗口请保持打开。
3. 选择阵营和胜负方式，点击“开始征程”。亮起的地图点可以移动；停在带有遭遇标记的驿道点会掷骰触发事件。

没有自动打开浏览器时，访问 [http://127.0.0.1:4173](http://127.0.0.1:4173)。非 Windows 系统可在项目目录运行 `node apps/server/server.ts`，然后打开同一地址。无需执行 `npm install`。

## 桌上怎么赢

- **走私者**从金矿取得碎金，送到边境黑市兑换；**官兵**可以稽查走私者，并将碎金运到墨尔根兑换。兑换会为阵营增加声望。
- 每名角色每回合掷行动骰，获得 **2–4 点行动点**，用来移动、采矿、补给或购买装备。卡牌和路上遭遇会带来额外机会，也可能让计划改道。
- **竞速局**：先达到 50 声望的阵营获胜。**火并局**：进行 30 轮后比较声望；同分平局。
- 一局有四名角色、双方各两人。人机版由你控制一方的两名角色；同屏模式由玩家轮流操作全部角色。

刚上路？先看游戏里的“新手入门”，或者阅读 [数字版规则书](docs/RULEBOOK_V1.md)。游戏提供逐步推进的人机与提示；人机是熟悉规则用的入门对手，并非竞技级 AI。

## 存档与项目内容

通过“保存行程”创建独立存档，可以命名、选择读取；同名时会先询问是否覆盖。存档保存在 `data/saves`，只属于本机游玩数据，不需要随游戏分享。若目录不存在，游戏会自动创建。

启动所需的主要内容是 `启动游戏.cmd`、`tools/`、`apps/`、`packages/`、`content/` 和 `docs/RULEBOOK_V1.md`。复制或打包时请保留项目的目录结构；地图及卡牌美术均包含在 `apps/web/assets/`。参考 PDF、Word、开发计划、试玩记录和 `tmp/` 下的渲染文件都不是运行游戏的必需文件。

目前是本地试玩版本：支持人机和同屏游玩，**不支持联网房间**；数值与人机策略仍需更多真人试玩校准。
