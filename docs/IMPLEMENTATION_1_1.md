# 本地对战版 1.1 开发记录

> **历史实现记录。** 本文保留当时的实现、验证和限制说明；不是当前规则或当前试玩结论。规则以 `RULEBOOK_V1.md` 为准，数值以 `content/balance.v1.json` 为准。

## 本轮交付

- 统一合法动作枚举：界面、人机经过同一个不可变规则引擎，响应者与当前行动者分离。
- 本地人机：玩家选一个阵营并操控两名角色；对手逐动作推进，到人类决策窗口等待。支持暂停、读档续局。启发式算法，不是训练模型。
- 前端：主菜单、模式/阵营设置、对局、规则指引、卡牌图鉴；地点、功能牌、装备分类操作；中文可搜索图鉴；合法路径选择及地图点击移动。
- 后端：修正出牌时限与范围、满手偷牌、禁入时长、蒙汗药酒、混淆控制、密封拆包、刑讯双问单开箱、稽查惩罚相加、矿产轮次重置、事件快照、铜锣、的卢、赤兔、拒马跨轮与拆除、装备卸下、回收出售及各地点次数。
- 存档：包含模式、阵营、待决策和规则版本。旧版文件原样保留，避免新规则静默重算旧局。
- 接口：串行处理本地请求，局面版本检测拒绝重复/过期动作，人机模式校验操控阵营。只监听本机。

## 人机决策边界

合法候选由完整裁判状态验证；候选本身仅包含公开可选指令，不提供动作抽牌/骰子预演结果。评分使用遮蔽视图，敌方手牌是背面占位符，牌库与随机数状态不可见，箱子内容不可见。评分优先交金、补给与采矿，次选有效攻击和购买，移动以公开地图最短路为基础。双箱只根据系统回答选箱。没有博弈树深搜或学习能力；需要真人试玩继续调平衡。

## 测试与待验证

规则与服务接口回归覆盖卡牌/事件/状态、完整人机三十轮及竞速局、动作原子性、存档和过期请求拒绝。运行：

```text
npm test
npm run check
```

本轮新版页面的浏览器自动化两次因工具审批检查超时未完成，不能将接口和语法测试等同于新版界面的实际点按及视觉验收。上一轮旧界面已做过实际浏览器验证。此次新菜单、图鉴与人机播放仍需补充端到端视觉检查，尤其窄屏和长卡牌列表。

## 有意保留的限制

- 仍是本地服务，尚无账号、网络房间、断线重连、安装包。
- 同屏模式靠玩家避看私密手牌；人机模式响应数据遮蔽对手手牌与分箱，但原始本地存档含完整状态。
- 自由交易没有开放；见规则书 1.1 裁定。界面只暴露目前已实现的动作。
- 规则及平衡仍属试玩版，人机强度仅为入门；自动对局完成不代表竞技平衡已验证。
