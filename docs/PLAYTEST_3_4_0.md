## 发现与修复

- 城市文字和圆圈之间存在点击空隙，点击稽查站丙的标签中心未打开路线。扩大可达节点命中范围并添加标签透明命中区域，随后通过界面再次打开路线并完成移动。
- 地图在提交期间缺少明确的不可点击语义，现与原有忙碌锁一致标记；手机触摸不触发双击缩放。
- 响应说明没有区分当前是否持有可用拒查牌，现按实际合法操作提示。
- 网络错误原文不便理解，现分别说明断线、超时、无效响应，以及重新同步后确认结果的处理方法。
- 教学结尾原本沿用正式结算提示，改为教学完成与退出入口；教学完成不会加入胜率统计。
- 320像素浏览器宽度下，页面320像素最小宽度叠加纵向滚动条导致横向溢出，取消页面最小宽度后大厅与教学不再溢出。
- 教学中途刷新后大厅沿用“继续当前对局”，改为“继续实操教学”，并展示已保留的教学步骤。
