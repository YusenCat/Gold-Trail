# 棋盘交互与人机策略改进

> **历史实现记录。** 本文的测试数量、试玩观察和未完成事项绑定当时的代码快照；不是当前规则或本轮试玩结果。当前平衡矩阵见 `PLAYTEST_REPORT.md`。

## 本轮交付

- 棋盘使用纸色底、淡墨山岭和地点建筑符号，取消整张说明书图片叠在地图下导致的文字干扰。原始素材仍保留。
- 官兵使用蓝甲头盔棋子，走私者使用朱衣兜帽棋子；编号、阵营、当前行动圈和可攻击目标圈分别表达不同信息。同格角色横向排列，死亡角色暂离棋盘。
- 所有合法移动终点都能点击，含免费移动和控制移动。先显示路线与服务端计算的行动点消耗，再确认执行。多条路线以选择卡列出，不使用下拉菜单。
- 功能牌常驻棋盘下方。点击卡牌后，地图突出合法角色目标或目的地；点目标后确认。响应牌依然严格走服务端响应窗口，不绕过出牌时机。取消或按 Esc 不会消耗卡牌。
- 角色棋子可点击查看公开状态。人机回合不显示敌方手牌；轮到人类响应者时切换其手牌。
- 添加回合顺序条、最新战报、资源筹码和正常／快速人机播放速度。打开对话框或离开对局时暂停自动推进。
- 合法动作接口附加 `actionPointCost`，由规则引擎试执行后计算；不返回试执行中的抽牌或骰子结果。
- 收缴窗口展示发动者、响应原因和甲乙箱按钮；询问记录保存全部真实回答，人机联合使用两次回答推断可能的分箱，不再被第二个答案覆盖第一条信息。旧存档没有问答数组时仍可加载，以原有最后一次回答继续。
- 玩家视角试玩后补充：矿脉余量、矿洞塌方和个人采矿次数提示；根据是否携金给出金矿／交金点目标；零行动点时直接提示结束回合。官兵与走私者同格却无行动点时，明确说明稽查需要行动点。新增结算面板、自动恢复状态与重开入口。
- 服务端每个状态变更后写入内部自动恢复文件；该文件不会出现在手动存档列表，重新启动服务时自动读回。

## 人机改进

仍为使用公开信息的确定性启发式对手，不是搜索树或训练模型。新增：距离与粮草余量共同决定补给路线；接近五十声望或三十轮终局时提前回程交金；优先进入可到达的安全点避免零粮饿死；路线计入行动消耗、敌人邻近风险与安全地点；避免重复买同槽装备，按促销价格判断预算；不重复施加已经存在的同类药酒惩罚；在交金点从密匣取金；只拆除能缩短当前目标路线的拒马。

这些是操作策略而非规则变更，保留规则版本 1.1.0 和既有存档兼容性。并不保证最优路线或竞技平衡，极端断粮与封路仍可能困住人机。

## 验证边界

规则与服务接口共 56 项测试通过，覆盖完整三十轮、五十声望竞速、隐藏信息隔离、官兵稽查的分箱—问话—选箱链路，以及自动恢复和手动存档隔离。前端 JavaScript 语法及内容一致性检查通过。

浏览器试玩已从全新走私者局和全新官兵局进行：事件旗帜、路线确认、采矿、市场刷新、同格棋子、行动点耗尽、对手自动行棋与浏览器刷新后的恢复均可见。一次官兵抵达稽查站时恰好耗尽行动点，说明“抵达即稽查”的直觉会落空；已补充针对性提示。尚未以人工逐步走完三十轮，因此平衡结论只作早期观察，不当作最终数值定论。
